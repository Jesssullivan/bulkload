## Done

- **Handoff moved out of the agent.**
  - `crates/bulkload-agent/src/handoff.rs` moved with `git mv` to the new
    workspace crate `crates/bulkload-handoff`. It is a lib plus the
    `bulkload-handoff` binary. The verb is now `bulkload-handoff verify` with
    the same flags; `bulkload-agent handoff-verify` is gone.
  - The agent binary no longer spawns sops, kubectl, gpg, gh, claude or codex.
  - A new test, `crates/bulkload-agent/tests/no_credential_tools.rs`, checks
    this two ways: it scans the agent sources for those programs, and it runs
    the binary to confirm `handoff-verify` is now an unknown subcommand.
  - The `PROBE_FAILED` refusal stays in bulkload-proto, because handoff
    still raises it.
- **One child-drain helper.**
  - The new `bulkload_agent::child::drain_bounded` reads a stream to its end.
    It keeps a bounded head, counts every byte, hands each chunk to a sink,
    retries `Interrupted`, and returns any other read error as a value.
  - Both former copies now call it: `git_carry::estimate::drain` (Git
    stderr) and handoff's `drain` (probe stdout and stderr).
  - Two proptests cover it. Head, count and sink agree with the stream, and
    an `Interrupted` read never ends a drain. A hard error is returned with
    the bytes read before it.
- **Shared proptest config.** `crates/bulkload-agent/src/test_support.rs` is
  byte-identical to the WP1 branch's copy (`prop_config`, fixed CI seed).
  Whichever PR merges second gets an identical-add, or a one-line `lib.rs`
  conflict.
- **Docs.** The AGENTS.md crate list names `crates/bulkload-handoff`.
