## CI fix and merge (2026-10-02), OI-1001-Q14/Q17, R-N125

- **Why CI failed when local `just rust-check` passed.** CI runs every gate
  inside `nix develop`, with the flake's nixpkgs toolchain: rustc and
  clippy 1.96.1, which matches `rust-toolchain.toml`. This lane ran
  `just rust-check` from a plain shell, where `cargo` on PATH is a
  nix-profile `rust-default-1.93.0`. Sting has no rustup, so
  `rust-toolchain.toml` was never applied. Clippy 1.93 does not fire
  `result_large_err` on the two closures in the r4 N1 contention test;
  1.96.1 does. Both CI clippy commands (with and without
  `--features bulkload-agent/fault-injection`) reproduced the error
  locally once run inside `nix develop .#default`. **Rule for this lane:
  run the gates through `nix develop .#default --command just ...`, as
  `just check` does.**
- **Lint fix:** the contention test boxes the `Refused` error
  (`.map_err(Box::new)`), as clippy's help suggests, with no blanket allow.
  `journal.rs` adds `clippy::cast_sign_loss` to the existing `st_dev` cast
  allow, since `dev_t` is `i32` on Darwin.
