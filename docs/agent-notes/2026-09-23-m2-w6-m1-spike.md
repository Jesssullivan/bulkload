## Findings that matter downstream

- **Q1 gate holds.** The list-mode sender with no trim equals upload-pack
  over the held tips, ancestors first, on 12 of 12 runs, in both object set
  and bytes.
- **Have order matters.** On P1, child-first haves send 3 objects / 5,018 B
  against 2 / 245 B.
- **Preflight is mandatory.** The R-N75 held-tip closure preflight must run
  before ingest.
- **Segment ordering.** Order by (type, basename, path): +20.1 % against
  +164.7 % for (type, path) on renamed lineages.
- **Reproducibility.** Pack bytes are reproducible only with the same git
  build and `pack.threads`. Apple and nixpkgs git 2.54 differ by up to 5.9 %.
- **Ledger.** P must copy alternates-only objects before its ledger ref is
  published.
- **Snapshot model.** One ref per snapshot stands at 2,000 parents. Never run
  `log --graph` over S.
