## Choices made (flag in review)

- **Journal:** an append-only text file, each line check-summed and sealed.
  The plan block is sealed by a digest record, so a torn begin reads as no
  journal. `flock` makes one session per `pack_id`.
- **Quarantine name:** `objects/incoming-bulkload-<pack_id>`,
  deterministic so recovery finds it. Git's own gc leaves `incoming-*`
  directories alone.
- **Ref ops:** `create` for an absent ref, `verify` for one already at its
  oid, and a refusal otherwise. No existing ref is ever moved, which is what
  keeps existing `refs/carry/*` digests unchanged. Publishing an update of
  a live ref is out of M1's scope.
- **Refusal codes:** `held_tip_closure_incomplete`, `segment_invalid` and
  `connectivity_missing` are all `GIT_HAVES_UNPROVABLE`, meaning
  re-negotiate (spike Q3).
- **The `.keep` message** is `bulkload git-carry-v2 <pack_id>`. Only a
  `.keep` holding exactly that message is dropped.
