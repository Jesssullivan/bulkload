## Done

On `origin/main`, the string "wired in by W4" appeared 35 times. It now
appears 6 times, all on `Qos`, which is left to WP1 (see Coordination).

**Deleted.** These items were dead in non-test builds:

- `TempFile` with `Staged`, `PublishError`, `TempTag` and `TEMP_TAG_HEX`;
- `sys::open_tmpfile`, `sys::link_tmpfile` and `proc_fd_reachable`, with the
  Darwin stubs of the first two;
- `sys::create_temp_named` and `TEMP_SEQUENCE`;
- `sys::rename_noreplace`, the single-directory form;
- `sys::kick`, `sys::preallocate` and `sys::read_advise`, on both
  platforms. WP9 PR 4 has not wired them; if it needs them it can restore
  them from git history;
- `sys::socket_buffers`.

**Kept, allowance dropped.** These were already live, so the W4 allowance
was stale:

- `c_name`, which `openat_beneath` uses;
- `sys::rename_noreplace_at`, which carry_v2 ingest uses. carry_v2 is
  frozen under OI-1003-Q15 and was not touched.

**Narrowed.**

- `Stat::permissions` is now `#[cfg(any(test, feature = "io-trace"))]`,
  since only the trace reads it.
- `fsync_raw` is `#[cfg(target_os = "linux")]`: Darwin's only caller was
  `kick`.

**Chunker and buf.** `io/chunker.rs` and `io/buf.rs` stay, as the brief
directs. Their allowance reason now cites gate (a), #88 and WP10 PR 3, in
place of "W4".

**Tests retargeted.**

- crash_check: the `recorded` tests now publish through
  `io::publish_noreplace`. Both paths run: the exclusive rename, and the
  counted `linkat`+`unlinkat` fallback under `force_rename_unsupported`
  (R-N119). The TempFile, named-temp and `/dev/shm` `O_TMPFILE` variants
  are gone.
- io/tests: the rename tests use `rename_noreplace_at`. Tests of the deleted
  calls are removed. The socket-buffer effect test is gone, because
  `io::transport_tests` still covers `tune_transport`'s socket, pipe and
  file contract.

**Docs.** The io module's call table and file list drop the deleted calls.

  branch deletes `Qos`, `qos_class`, `set_thread_qos` and `thread_qos`, and

## Not done

- `trace::SyncKind::Kick` and `Event::Create { name: None }` are
  crash-checker model cases with no producer now. The model and its tests
  still exercise them. Deleting them is a model change; it was left out
  rather than mixed into dead-code removal.
- Darwin was not compiled locally. The nix dev shell on sting has no
  `aarch64-apple-darwin` standard library (`cargo check --target` fails
  with E0463).
  The Darwin edits mirror the Linux ones line for line. CI runs only on
  `tinyland-nix` (Linux), so a Darwin build on neo (`cargo clippy
  --workspace --all-targets -- -D warnings`) is still needed before merge.
